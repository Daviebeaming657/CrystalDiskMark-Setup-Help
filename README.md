## ⚠️ Troubleshooting Common Setup Failures

If the installation stops or returns an error, try these fixes to resolve issues on Windows 11.

### Setup Fails Immediately
This often happens due to background security software. Temporarily disable your antivirus or Windows Defender during the installation. Re-enable it after the software installs successfully.

### Permission Denied Errors
Right-click the installer file and choose Run as administrator. This forces the installer to bypass standard user restrictions that prevent file creation in system directories.

### Missing File Errors
If the application reports missing files upon launch, the download likely corrupted. Delete the existing installer file and download it again from the primary link. Ensure your internet connection remains stable during the entire download process.

### Windows 11 Compatibility Warnings
Windows 11 includes strict security features that might block unrecognized installers. If you see a blue window saying "Windows protected your PC," click More info, then click Run anyway to continue.

## 📈 Running Your First Benchmark

Once you complete the installation, you can test your drive speed.

1. Open the CrystalDiskMark application from your Start Menu.
2. Select your target drive from the drop-down menu in the top left corner.
3. Select the number of passes (5 is the standard choice for accuracy).
4. Select the test size (1GiB is recommended for modern solid-state drives).
5. Click the All button to begin the benchmark.
6. Sit back and watch the read and write speeds appear in the table. 
7. Do not use your computer for heavy tasks while the benchmark runs. Open browser windows or background apps skew the final results.

## 📋 Tips for Accurate Results

*   Close all other open programs before you start the test.
*   Run the test while the drive is at least 20 percent empty. Completely full drives often show lower performance speeds.
*   If you test an external USB drive, ensure it is connected to a USB 3.0 or USB 3.1 port. Ports marked with blue plastic inside are usually the fastest.
*   If the test hangs at 0 percent, your drive might be busy with a background Windows update. Check the Task Manager to see if your disk usage is at 100 percent before you start.

## 🔧 Advanced Configuration

Most users do not need to change settings beyond the default configuration. If you require specific test parameters, use the Settings menu to adjust the block size or the test queue depth. These settings are meant for developers and technicians evaluating hardware controllers. Incorrect settings result in misleading performance numbers. Stick to the default modes unless you have a specific reason to change them.
